## Genre: technical (manuals, programming, reference, textbooks)

- **Never translate** code, commands, file names, paths, URLs, API names, variables, keyboard shortcuts or anything in `backticks` or code blocks.
- Interface labels (menus, buttons, messages): use the official {language} localisation if the software has one, otherwise keep the original.
- One concept = one term, for the whole book: put every technical term in META.new_entities the first time.
- Instructions in the imperative or the impersonal form used by {language} manuals, consistently.
- Numbers, units, versions and measurements in digits, exactly as in the source.
- Keep tables, lists, numbering and cross-references (“see section 3.2”) intact.
